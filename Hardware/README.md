# Hardware: the physical machines

Mechanical reference for Norsk Data machines - cabinet sizes, weights, cage positions - and
the 3D models built from those numbers.

| File | What it covers |
|---|---|
| [ND-PHYSICAL-MODELS.md](ND-PHYSICAL-MODELS.md) | What each cabinet is, how big it is, what it weighs, what it draws, and which model names sit in which box. Every number is quoted from a named manual. Section 9 covers the NORD-1, NORD-10/S and NORD-50. |
| [3D-Models/](3D-Models/README.md) | FreeCAD sources (`.FCStd`) with `.obj` / `.stl` exports for the ND-100 Compact, the ND-100 Satellite, the ND-5900 large cabinet and the ND 246 terminal, plus the Python scripts that make the 1:10 print files |
| [HANDOFF-3D-MODEL-2026-08-02.md](HANDOFF-3D-MODEL-2026-08-02.md) | Handoff for the cabinet reconstruction: the dimensions and geometry needed to build and 3D print scale models, starting with the ND-100/CX Compact |
| [HANDOFF-ND246-TERMINAL-2026-08-04.md](HANDOFF-ND246-TERMINAL-2026-08-04.md) | Handoff for the ND 246 NOTIS terminal model |
