# NORD-1 Manuals

**Reference and hardware documentation for the NORD-1 - Norsk Data's first minicomputer (1968-1972 era)**

[← Reference Manuals index](../README.md)

---

## 📖 Overview

This sub-collection holds the NORD-1 documentation set: the CPU reference manual, the
two-volume hardware manual, and the connector / I-O-channel / power-system description.
Those four are primary source material for the earliest Norsk Data architecture.

The fifth file, the ITT-1600 binder, is **not** NORD-1 documentation - see its row below.

| Manuals | Total Lines |
|---------|-------------|
| **6** | ~18,200 |

### Not NORD-1 - filed here because it came in the same binder

| Manual | Document # | Lines | Description |
|--------|-----------|-------|-------------|
| **Binder NORD-1 ITT-1600** | - | 6,901 | **NOT a NORD-1 document.** Norwegian study notes, "Assemblerspraak paa ITT-1600", on the assembly language of the **ITT-1600** - a different computer (16 bits + 1 parity bit, A/B/X registers, C overflow bit, Q stack pointer at octal 40, 512-word protection sectors), used with an ITT telex exchange. Bound in with Texas Instruments datasheets (SN54S181/SN74S181 ALU). Its NORD-1 link is that the author repeatedly compares the two machines in the margins ("tilsvarer IR-registeret i NORD-1"). Valuable as a period document; **do not cite it for any NORD-1 fact.** In particular its parity flip-flop and the SSC/SPS skip instructions belong to the ITT machine, not the NORD-1. |

**Key Topics:** NORD-1 CPU architecture, instruction repertoire, hardware logic, module descriptions, flow diagrams, connectors, I-O and data-channel systems, power system, peripherals

**Note:** ND-01.004.01 exists as two volumes (Vol I logic/modules, Vol II flow diagrams) - both are included. The Reference Manual is the latest (1970 February) edition.

**Note:** the ITT-1600 binder was mislabelled here as a "NORD-1 peripheral binder" until 2026-08-27, when it was read while checking [History/NORD-1.md](../../History/NORD-1.md) and found to be about a different computer.
